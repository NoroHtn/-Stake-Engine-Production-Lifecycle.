# Stake Engine Production Lifecycle

Employee-facing production workflow for building and publishing games through Stake Engine.

## Live site

This repository is configured for GitHub Pages. The site is a static, self-contained workflow with:

- English, Armenian, and Russian content
- Persistent dark and light themes
- Nine production phases and role-specific task cards
- Print / Save PDF support
- Responsive desktop and mobile layouts

## Files

- `index.html` — complete production lifecycle website
- `workflow-controls.js` — language, theme, print, navigation, and specialist-module controls
- `.github/workflows/pages.yml` — GitHub Pages deployment workflow
